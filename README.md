## AsioScan (Work in Progress)

AsioScan is a cross-platform TCP port scanner written in modern C++ using **Boost.Asio**.
The project is currently under active development and focused on building a clean, modular foundation before adding advanced scanning features.


### Planned Features

* TCP connect scanning (initial implementation)
* Single-host and multi-host scans
* Port ranges and common-port presets
* Text and XML output formats
* Command-line interface similar to `nmap`
* Future OS-specific scan types (e.g., SYN scan)

### Disclaimer

This project is experimental and educational in nature.
APIs, behavior, and structure are subject to change as development continues.
